A quick guide to the atlas
  1. Select a node on the map or in the source directory. Follow the trace arrows from each source into the component that uses it. Separate lines show separate branches; dashed lines show registered dependencies. Use the trace chevron to fold the sidebar away; selecting a node opens it again.
  2. View parameters opens that node’s values. Filter by received inputs, local definitions or unconfirmed origins.
  3. Select a value to isolate its trail. Open its origin evidence or an exact source location to inspect the record.
  4. Assumptions & gaps appear on each source’s record in pane 02, in the source directory and in the Assumptions map arrangement. A badge on a card counts open or stale entries; a stale entry means its basis source moved in the register since the judgment. Draft assumption writes a JSON entry with the current hashes for you to paste into the register.
  5. Clear selection undims every node and keeps your map position. The dashed-square button fits the full map without changing your selection. Back restores your previous selection and filters.

“Local setting” means a definition retained in this node, not proof that it was first authored there. A formula is shown as a formula until its result is available. Unlinked origins stay unconfirmed.
